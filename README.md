# Aegis-Antivirus
AEGIS — Next-Gen Security é um projeto acadêmico com duas partes: um site de vendas e painel do cliente (Flask + SQLite) e um aplicativo antivírus para desktop (Tkinter). O app verifica arquivos por assinaturas SHA-256 e heurística, isola ameaças em quarentena reversível, oferece proteção em tempo real e pode usar o ClamAV como motor adicional.
